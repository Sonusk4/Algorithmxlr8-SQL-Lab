# Patients with DIAB1

**Level:** `Level 2` · **Topic:** `Strings`

## Problem

The `Patients` table stores each patient's conditions as codes separated by single spaces. The list can be empty.

The code for type 1 diabetes always starts with `DIAB1`. Find the patients who have it. A code only counts when `DIAB1` is at the start of one of the codes.

Return `patient_id`, `patient_name` and `conditions`. The rows can be in any order.
